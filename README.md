# Edebiyat Atlası

Edebiyat Atlası, YKS ve lise edebiyatına hazırlanan öğrenciler için geliştirilmiş bir mobil eğitim uygulamasıdır.

Uygulamada edebiyat dönemleri, sanatçılar, eserler, zaman tüneli, testler ve kullanıcı ilerleme sistemi bulunmaktadır.
